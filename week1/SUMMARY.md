## Concepts learned
- **Variables and data types:** `int`, `float`, `str`, `bool`; type checking with `type()` and conversion such as `float(input())`.
- **Operators:** arithmetic (`+ - * / ** %`), comparison, and logical (`and`, `or`, `not`).
- **Input/output:** `input()` for user data and f-strings (`f"{x:.2f}"`) for formatted output.
- **Conditionals:** `if / elif / else` to branch logic.
- **Loops:** `for` for iterating over collections, `while` for repeating until a condition changes.

## Hands-on
- `temperature_converter()` converts between Celsius and Fahrenheit and validates input.
- `calculator()` supports `+ - * / ** %` in a `while` loop and handles bad input and division by zero.

## Client project
A weekly temperature report that computes the average (28.89 C), the hottest and coolest days, and the days above average.

## Key takeaway
Validating input with `try/except` and conditionals makes even small scripts reliable. Writing logic as small functions made it easy to reuse.

**Run:** `python week1_intro_python.py`
